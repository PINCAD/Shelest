# Шелест — веб-клиент

Веб-клиент отделён от Android-приложения и Django API. Исходники и публичные материалы находятся в `web/`, собранный сайт — в `web/dist/`.

## Локальный запуск

Нужен Node.js 20 или новее. В PowerShell из этой папки:

```powershell
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://127.0.0.1:5173`). Для работы `/api` локально должен быть запущен Django на `http://127.0.0.1:8000`; Vite перенаправляет запросы туда.

## Сборка и перенос на сервер

```powershell
npm run build
```

Размещается только содержимое `web/dist/`. API проксируется из того же домена по
`/api/` к Django; отдельный CORS для этого не нужен. Сборка/proxy задаются в
`vite.config.ts`, API-клиент — `src/cloud.ts`. Локальные книги хранятся в IndexedDB,
облачные файлы Premium — отдельно на сервере; пользовательские книги в dist не входят.

Google-вход, вход по логину/паролю и облачная синхронизация подключены. Бесплатным
аккаунтам передаются метаданные/позиции; файлы должны быть импортированы на обоих
устройствах. Premium может хранить и синхронизировать оригиналы в пределах квоты.
Очистка данных сайта удалит локальную библиотеку; облако не гарантирует восстановление
неотправленных файлов, заметок и настроек.

Общая Kotlin-логика находится в ../shared, общие UI-компоненты — в ../shared-ui.
React остаётся оболочкой и платформенным адаптером. Полная сборка обеих платформ:
scripts/build-release.ps1 -BrowserTests из корня проекта с настроенным браузером.
Публиковать лучше архивом через server/deploy/publish-web.sh, а не перезаписью dist
вручную: сценарий проверяет хэш, сохраняет предыдущую версию и старые assets.
Карта проекта и инструкции передачи: ../PROJECT_HANDOFF.md.
