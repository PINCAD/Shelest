# Веб и Android: проверка 9 октября 2026, версия 1.4.10

## Исправления этого обновления

- Веб получил отдельный визуальный слой `design.css`: единая светлая/тёмная палитра,
  типографика, карточки, контролы, адаптация 320–1440 px и reduced motion.
- Компактные строки безопасности открывают доступные диалоги; настройка TOTP
  пошаговая, QR генерируется локально лениво. Коды можно копировать/скачивать,
  случайное закрытие до подтверждения сохранения заблокировано.
- Переименование, PDF-заметка и подтверждение удаления используют один Dialog.
  Последнее удаляет только после явного подтверждения; облачные правила сохранены.
- Состояния недоступности Google, ошибки кода и загрузки оформлены в общем стиле.
  Не менялись нативные Android-экраны и серверная схема безопасности.

- Повторное выделение той же цитаты меняет существующий цвет, не создаёт дубль.
- Сохранение текста заметки не возвращает старый цвет: DAO обновляет поля отдельно.
- Выделения, пересекающие абзацы/элементы и старые пометки, обрабатываются по текстовым узлам.
- Цвета в диалоге равномерно распределены; поле заметки ограничено по высоте.
- «Обновить» остаётся рабочей и доступной кнопкой, но без визуального эффекта нажатия.
- Веб: режим страниц / вертикальная прокрутка; переключение сохраняет текстовый якорь.
- Двухстраничный режим убран по просьбе пользователя; одна страница на всех экранах.
- PDF-инструменты на ПК справа, настройки пера раскрываются вправо, на мобильном — снизу.
  Страница подгоняется по ширине и высоте; при раскрытии инструментов масштаб не меняется.
- На сайте добавлены смена логина/пароля и настройка TOTP с резервными кодами.
  Android и веб запрашивают второй фактор при включённой защите, включая Google-вход.

## Что совпадает, а что ещё отличается

| Функция | Состояние веба относительно Android |
|---|---|
| Google / логин-пароль, Premium, библиотека, облачные книги и место чтения | Реализовано; авторизация платформенная |
| Словарик, цель дня, новое название, заметки/выделения/PDF-штрихи | Синхронизируются; полная авто-синхронизация после выхода из читалки |
| Шрифты, восемь тем страницы, размер, интервал, поля, выравнивание | Реализовано |
| Вертикальная прокрутка / постраничное чтение | Реализовано для текстовых книг; PDF имеет собственную прокрутку/масштаб |
| Две страницы на ПК | Убрано по просьбе пользователя |
| Оглавление | Реализовано для поддерживаемых текстовых публикаций |
| PDF-перо, цвет, толщина, ластик, удаление штриха, отмена, заметки-пины | Реализовано; мобильная вёрстка адаптивная, не буквально идентичный нативный интерфейс |
| Выбор текста PDF | Есть для PDF с текстовым слоем; OCR сканов отсутствует |
| Озвучка, скорость, таймер сна | Есть через speechSynthesis; зависит от голосов браузера/ОС, не равно нативному фоновому сервису |
| Автопрокрутка с выбором темпа | Нет отдельного пользовательского управления в вебе |
| Фоновые звуки / пользовательский звук | Не перенесены |
| Полный поиск определений и офлайн-словарь | Веб сохраняет слова и принимает определения из Android; собственного полноценного словаря пока нет |
| Поиск внутри книги | Движок умеет поиск, но полноценная поисковая панель веба не подключена |
| Закладки и управление списком пометок | Нет полного аналога нативного списка, переходов и экспорта |
| Редактирование/удаление текстовых заметок в вебе | Протокол готов; полноценный интерфейс редактирования списка не добавлен |
| Настоящее сгибание страницы | Нет: доступные веб-анимации не равны Android curl |
| Яркость, кнопки громкости, удержание экрана, ориентация | Платформенные отличия; полного аналога Android нет |
| Статистика/стрик и цели | Базовая статистика есть; детальная нативная аналитика и межустройственная статистика не полностью совпадают |
| Вступительный тур, виджеты, полный офлайн-запуск сайта | Полного аналога в вебе нет |

## Проверки и ограничения доказательств

Проверялись production-сборка и общий движок в изолированном Chrome:
широкая вёрстка, размеры 320/768/1440, PDF-текст/рисование/ластик/пины,
шрифты, цвета, речь с тестовым speech API, две колонки, прокрутка,
возврат к страницам, сужение окна, сохранение позиции и отсутствие JS-ошибок.
Мобильные размеры в браузерных тестах — эмуляция, не физический браузер телефона.
Android: JVM-тесты, общий движок и реальные транзакции Room в отдельном
эмуляторе (повторное выделение, смена цвета, сохранение заметки, синхронизация).
На личном телефоне instrumentation не запускать, данные не очищать.

Это аудит, а не заявление о полном паритете: перечисленные отсутствующие
функции не считаются реализованными этим обновлением.
