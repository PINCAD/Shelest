# 1.4.12 / code 16 — библиотека и осторожная оптимизация

## Изменения

- LibraryViewModel использует один общий StateFlow списка Room для счётчика,
  выбора и отфильтрованной библиотеки, вместо двух подписок на DAO.
- Поиск: текст поля обновляется сразу; фильтр ждёт 120 ms между вводом символов.
  Очистка выполняется без задержки. Пробелы вокруг запроса игнорируются.
  Работа остаётся на Dispatchers.Default; нормализованные ключи сортировки
  вычисляются один раз на книгу, Locale.ROOT исключает зависимость от локали.
- ShelfBook размечен Immutable: все его поля — неизменяемые скалярные значения.
- Карточка имеет один обработчик нажатия/долгого нажатия и скруглённую область
  отклика; убран вложенный кликабельный контейнер обложки.
- Названия занимают две строки, авторы выровнены. «Новая»/процент вынесены
  под обложку, а не закрывают рисунок; сердце остаётся акцентным.
- Подложка недавних ограничена 472 dp, обложки не растягиваются на планшете.
- Шрифты WebView выдаются потоком assets: нет дополнительного readBytes копирования
  каждого полного шрифта при обновлении документа/переходе сегмента.

Это устранение конкретной лишней работы, не обещание измеренного ускорения
в процентах. Разбор документов, текстовые якоря, база Room, подпись и
синхронизация не менялись; сетевой барьер перед открытием сохранён для точной позиции.

через существующий журнал персональной синхронизации без миграций Room/IndexedDB.

## Проверки

4 новых JVM-проверки LibraryFilterTest: поиск, сортировки, сохранение ссылок
и прогресса, независимость от локали. DocumentCacheTest/ShelfStatusTest проходят.
Полная локальная сборка Android/shared/JS/TS и браузерные регрессии выполняются
через scripts/build-release.ps1 -BrowserTests; публикация отдельно.

Android UI проверяется на отдельном emulator-5554; не на личном телефоне.
Первый прогон после холодного запуска был закрыт системным ANR System UI,
не сбоем приложения. После восстановления системы библиотека/выделение/шрифты
прошли. Новый accessibility-тест уточнён: узел описания может быть отдельным
от предка — владельца действия. Проверяется один владелец клика, выравнивание
авторов, «Новая» и проценты, реальные packaged шрифты и закрытие потоков.
Скриншоты: app/build/optimization/ (синтетические книги, не данные пользователя).

Физический телефон по USB в этом прогоне отсутствует. APK не установлен
на личное устройство. Сайт/API не публиковались, серверные данные не менялись.
