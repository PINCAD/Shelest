# Исправление геометрии читалки, 10 октября 2026

Исходники: Android 1.4.19, versionCode 23, applicationId com.lexiread.app.

## Изменения

- PagedHtmlReader больше не резервирует постоянные 56 dp сверху и 82 dp снизу.
  Системные панели по-прежнему исключены из текстовой области. Показ инструментов
  не меняет размер WebView и не запускает новую пагинацию. Панели накладываются
  поверх страницы временно; их можно убрать отдельной кнопкой.
- ReaderSettingsSheet имеет фиксированную высоту независимо от вкладки и значений.
  Каждая вкладка хранит собственную позицию прокрутки. PDF не показывает вкладку
  текста, которая не влияла на документ.
- Выбор шрифта и анимации имеет равные карточки в два столбца, числовые значения
  фиксированной ширины. Переключение параметров не сдвигает кнопки.
- Нижняя панель ограничена 560 dp, отступает на 16 dp от краёв, равномерно
  распределяет инструменты. Узкие экраны сохраняют горизонтальную прокрутку.
- PDF-кнопка завершения режима не добавляется/удаляется при включении пера.
  Неактивная кнопка приглушена и отключена. Расширенные настройки открываются
  над рядом инструментов, с фиксированной высотой и внутренней прокруткой.
- Сборочный scripts/build-release.ps1 больше не подменяет подписанный публичный
  APK отладочным APK. Веб-архив сохраняет существующий download и его manifest.

## Подпись и личный телефон

Подключён Samsung SM-S928B (RFCXA1F5N6M), на нём release 1.4.18/code22.
Приложение не удалялось; данные, аккаунт и библиотека не очищались.
Инструментальные тесты выполнялись только на эмуляторе.

Unsigned APK: app/build/outputs/apk/release/app-release-unsigned.apk.
Для установки поверх существующей версии требуется пользовательский ключ key0.
scripts/sign-release-local.ps1 получает пароли через локальное маскированное
окно Windows Forms и передаёт их apksigner по stdin. Паролей нет в аргументах,
логах или файлах. После подписи проверяет совпадение SHA256 сертификата:
7045398b2c08a02e3d22f7ccfced88880128887e945373d47045a9efef199d20.

Пользователь закрыл локальное окно подписи; signing-status.json содержит
ok=false, "Подпись отменена пользователем." Подписанного APK пока нет.
После повторного согласованного запуска подписи сборка и результат появятся в
artifacts/reader-repair-20261010/shelest-1.4.19-release.apk и signing-status.json.
До ok=true не устанавливать APK на личный телефон.
После этого: adb install -r, проверить сохранённые книги/аккаунт/позицию,
чтение без панелей, настройки и PDF-инструменты без пометок в личных документах.
