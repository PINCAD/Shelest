# 1.4.11 / code 15 — листание и оформление книги

## Причина смещения

Android WebView/Blink использует дробные размеры в единицах 1/64 CSS px.
computedStyle сериализует ширину с меньшей точностью: 360.328125 -> 360.328.
Повторное назначение этой ширины контейнеру могло дать 360.3125. Скролл при этом
сдвигался на исходную ширину; ошибка накапливалась по колонкам.

До исправления новая регрессия app/tests/paged-reader.test.cjs падала на странице
501 при ширине 360.333: начало текста x=10.25 вместо поля 18 px. После исправления
ReaderDocument нормализует размеры к 1/64 px, все проверки выравнивания проходят.
Тест дробного scrollport важен: одно изменение iframe-width округляет viewport
Chrome до целых пикселей и раньше не воспроизводило Android-случай.
Этот тест включён в scripts/build-release.ps1 -BrowserTests.
