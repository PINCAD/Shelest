# 1.4.16 / versionCode20 — 10 октября 2026

## Изменения

- HTML: пункт «Читать отсюда» в меню выделения. Сохраняется реальный Range,
  а не первое совпадение слова. Озвучка начинается внутри предложения.
- PDF с текстовым слоем: такое же действие в панели выделения; контекст берётся
  из выбранных PDF-слов. Порядок pageText и pageWords одинаков (sortByPosition).
- «С этой страницы» использует точный character/context вместо первого абзаца.
  Неоднозначное/отсутствующее совпадение объясняется, не заменяется предложением0.
- Отсутствующий движок/русский голос, ошибка speak и аудиофокус получают сообщения.
  Ошибка не считается окончанием главы/PDF-страницы и не двигает книгу дальше.
- Сохраняются пауза и offset внутри предложения. Подготовка главы вычисляется
  отдельно и применяется после проверки отмены coroutine; старый запрос не
  должен заменить новую главу. Вместо двух нормализованных индексов остался один.
- Android WebView: одинаковая целочисленная CSS-ширина scrollport и column stride;
  наблюдается внешний page-frame. Подтверждённый drift page index500 исправлен.
- До начального размещения вертикальный reader не отправляет промежуточные
  позиции/готовность. В обоих режимах восстановление ждёт двух стабильных
  ненулевых размеров viewport. Тест тоже ожидает фактический placed/paged.
- Рекомендации: независимые бюджеты профиля2сек/источник поиска4сек,
  быстрые ответы показываются до окончания всех запросов. Не теряются быстрые
  сведения о вкусе при тайм-ауте другого источника. Кеш10мин, максимум8 наборов;
  учитывается состав библиотеки. Ручное обновление сбрасывает кеш.
- Описания: FantLab/Wikipedia параллельно, по1.5сек на источник/название,
  запасной поиск автора1сек. Успешные ответы сохраняются прежним кешем.
- Веб: тот же фикс страниц и защита начального размещения. Выделение+«Слушать»
  начинает чтение с конкретного слова, а не читает только выделенный фрагмент.

## Проверки

- 127 Android JVM tests, shared JVM, compiled Kotlin/JS parity, TypeScript/Vite.
- 21 Android instrumentation tests на собственном Pixel_9_Pro emulator,
  Android37, 2400×1800 density240: HTML restoration/selection/fractional columns,
  PDF selection/«Читать отсюда»/renderer, sync conflicts/personal/collections,
  brightness/keepScreenOn. Отдельный тест искусственно задерживает размер0×0.
  Финальный полный прогон прошёл (21/21); эмулятор выключен, size/density сброшены.
- При промежуточном прогоне возник ранний vertical restoration failure:
  отдельный повтор прошёл, стресс-прогон выявил повтор. Диагностика подтвердила
  initialLayout=[3,false,0,0,...], finalLayout=[3,false,1600,1200,...]; это реальная
  гонка измерения, из-за которой выбирался percent87 вместо exact scroll1234.
  После ожидания ненулевого стабильного viewport шесть повторов прошли.
  Не выдавать это за проверку каждого старого
  устройства/версии WebView или всех исторических якорей пользователя.
- PDF-тест исправлен для landscape: accessibility bounds обрезает высокую
  картинку, поэтому координата берётся по реальному аспекту LETTER fixture.
  Сохранились проверки конкретного выбранного слова и нового speech context.
- Chrome: fractional/tablet/portrait↔landscape, final page501, reopening,
  foreign-layout anchor, styles/animations/autoAdvance, exact DOM selection.
- Web UI tests: library/account/MFA/settings/collections, desktop/tablet320px,
  HTML/PDF. На опубликованном сайте дополнительно проверено selected word→speech
  continuation; speechSynthesis подменён, звука/личных API-записей не было.
- Node sync tests: позиции/файлы/offline/stale ACK/названия/словарик/цели/пометки/
  коллекции/изоляция аккаунтов прошли. API/схема БД не изменялись; реальные HTTPS
  roundtrips проверены в предыдущем TABLET-SYNC-AUDIT-20261009.md.
